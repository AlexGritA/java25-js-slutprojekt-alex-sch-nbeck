# FYM - Find Your Movie

Built for a school assignment at Grit Academy, this app lets you browse and search for movies and people using the TMDB API.

## What it does
Search for any movie or person, sort the results however you want, and click a card to get more details. On load you get the top 10 rated and most popular movies right away.

## Built with
JavaScript ES Modules, Bootstrap 5, and the TMDB API. No frameworks, no build tools.
